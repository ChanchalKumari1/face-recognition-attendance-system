# Attendance System with Face Recognition

This project is a smart attendance system based on face recognition. It uses a camera to detect and recognize faces and automatically mark attendance in real time. It is useful for schools, colleges, and offices to make attendance tracking fast, secure, and contactless.

---

## Features

- Face recognition based attendance system  
- Live camera face detection  
- Automatic attendance marking (Present/Unknown)  
- User registration with face capture  
- Attendance saved in CSV file  
- Simple and easy-to-use system  
- Real-time processing

## How It Works
---

1. Camera starts and captures live video

2. System detects faces in real time
 
3. Compares detected face with dataset

4. If match found → marks Present with time

5. If no match → shows Unknown Face

6. Attendance is saved automatically in CSV file

---

##Notes
Use good lighting for better accuracy

Keep face images clear and front-facing

One image per person is recommended

Keep camera stable during detection
